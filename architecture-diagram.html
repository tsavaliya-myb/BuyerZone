③ Processing Worker CLIP

tasks/process_message.py → services/processing.py
Validate magic-bytes → CLIP embed (512d) → dedup in Qdrant (cosine > 0.96, 30d, same wholesaler) → upload to R2 → atomic PG + Qdrant write. Rollback on failure.
tasks/staleness_check.py → services/staleness.py
Marks products status="stale" after STALENESS_DAYS (default 30).
▼   dual write   ▼PostgreSQL row + Qdrant vector (atomic, rolled back on error)

Database Models (SQLAlchemy 2.0 — Mapped[...])

products

  • id UUID · PK
  • qdrant_id UUID · unique — vector link
  • wholesaler_id → wholesalers.id
  • chat_id BigInt → monitored_chats.chat_id
  • telegram_msg_id BigInt
  • name, raw_caption, price Numeric(10,2), currency
  • image_url, image_key (R2)
  • source_platform = "telegram"
  • status: active · stale · removed
  • received_at, created_at, updated_at
  • Indexes: wholesaler, status, received_at

wholesalers

  • id UUID · PK
  • name, telegram_id (unique), telegram_username, phone
  • is_active · created_at · updated_at
  • 1 ← N → products

monitored_chats

  • id UUID · PK
  • chat_id BigInt · unique
  • chat_name · chat_type (group · channel · supergroup)
  • is_active, added_by → admin_users.id, added_at
  • 1 ← N → products

ingestion_logs

  • id UUID · PK
  • chat_id · telegram_msg_id
  • status: processed · skipped · failed · duplicate
  • reason (text)
  • product_id → products.id (nullable)
  • processed_at

admin_users

  • id UUID · PK
  • username, email (unique)
  • hashed_password (bcrypt via passlib)
  • is_active, created_at

Qdrant collection — product_embeddings

  • vector: 512-d · cosine distance
  • payload: product_id, wholesaler_id, status, received_at
  • Created on startup by ensure_collection()
  • Dedup filter: same wholesaler, last 30d, score > 0.96

Key cross-process flows

  • Admin adds chat: api → HTTP → ingestion:8001/dialogs/resolve → writes monitored_chats → reload whitelist
  • New Telegram message: ingestion → download image → enqueue_message (Redis) → worker consumes → CLIP + dedup + dual-write
  • Image search: client → api/search/image → clip.embed_image → Qdrant top-k → PG enrich (wholesaler join) → response
  • Staleness: ARQ cron daily 02:00 UTC → flips products older than STALENESS_DAYS
  • Catch-up: on listener boot, replays up to 100 msgs/chat since last logged telegram_msg_id

Security, Config & Thresholds

Auth tiers

  • Admin — Bearer JWT · role claim · require_admin
  • Internal — static API key · verify_internal_token
  • User — Bearer JWT · get_current_user (search, products)
  • JWT HS256 via python-jose; passwords bcrypt via passlib

Tunables (env)

  • DEDUP_SIMILARITY_THRESHOLD = 0.96
  • STALENESS_DAYS = 30
  • MAX_CONCURRENT_DOWNLOADS = 20 (ingestion)
  • CATCH_UP_LIMIT = 100 / CATCH_UP_FIRST_RUN_HOURS = 24
  • ARQ max_jobs = 10 · job_timeout = 600s
